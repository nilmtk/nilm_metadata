NILM Metadata
=============

NILM Metadata gives energy datasets a shared vocabulary for appliances,
meters, buildings, and dataset provenance. Use it when you need consistent
names and relationships across datasets.

Start here
----------

* Follow the :doc:`tutorial` to describe a dataset in YAML.
* Use :doc:`dataset_metadata` for the full dataset, building, meter, and
  appliance field reference.
* Use :doc:`central_metadata` to understand or extend the controlled appliance
  vocabulary.
* Return to the `NILMTK start page <https://nilmtk.github.io/>`_ to convert
  energy data, run a model, or reproduce a benchmark.

This project defines metadata. It does not distribute energy readings,
disaggregation models, or leaderboard results.
